# 📍 Roadtrip Explorer

Une Progressive Web App (PWA) autonome, statique et hors-ligne conçue pour traquer un roadtrip entre Toulouse, l'Espagne et le Sud de la France.

## 🚀 Caractéristiques
- **100% Statique** : Hébergeable gratuitement sur GitHub Pages.
- **Zéro Framework / Zéro Build** : Construit en HTML5, CSS3, et ES6 Vanilla JS.
- **Mode Hors-ligne (PWA)** : Service Worker intégré pour mettre en cache la carte et les données.
- **Leaflet & OpenStreetMap** : Cartographie performante et respectueuse de la vie privée.
- **Mobile-First UX** : Bottom Sheet pour les détails, filtres horizontaux, mode sombre natif.

## 🛠️ Structure du Projet
Voir l'arborescence demandée. Les données vivent dans le dossier `/data/` sous forme de fichiers JSON, permettant une mise à jour facile sans toucher au code.

## ⛺ Données & Catégories gérées
Bivouacs, Campings, Points de vue, Randonnées, Baignades, Eau potable, Douches, Toilettes, Stations essence, Supermarchés, Restaurants, Parkings.

## 💻 Installation & Déploiement
1. Clonez ce dépôt.
2. Ajoutez vos photos dans `assets/images/`.
3. Poussez sur GitHub et activez **GitHub Pages** (Settings > Pages > Deploy from branch `main`).
4. Ouvrez le site sur votre smartphone et cliquez sur "Ajouter à l'écran d'accueil" !
